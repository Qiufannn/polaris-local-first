# 小账本与电子书共读

本人要求先暂停手机屏幕操作，等待官端数据导出；本轮优先改善记账，并确认共读目标是在原小屋读电子书、AI 跟着当前章节一起读。继续保留原小屋三页、头像、背景和排版，只完善原账本/书架入口内的功能。

## 小账本

- 人民币收入/支出，金额以整数分保存；日期、常用/自定义分类、名称与备注。名称可留空并使用分类，金额必须大于零且最多两位小数。
- 月度收入、支出、结余、分类汇总与可选月预算；结余指收入减支出，不是银行卡余额。预算为 0 时不设置上限。统计包括整月所有有效记录，不随屏幕分页缩小。
- 折叠筛选支持收支、分类和文字；更正保留版本，指定账目可以收起/恢复。列表每次展示有限条数，月汇总不受影响。
- 未知提交保留原请求编号；不同新草稿先核对上一笔。服务器已确认保存而列表刷新失败时，仍报告已保存，避免误导重复记账。核对到旧提交后清理对应旧草稿，保留新草稿。
- 可按当前筛选导出 CSV，处理逗号/引号/换行，并防止表格公式被文本单元格直接执行。
- AI 沿用 `ledger_save`，新增 `ledger_summary`、`ledger_budget_save`、`ledger_archive`。查询优先读简短月汇总；更新需要当前版本和稳定请求编号。不接银行、不自动读支付应用，也不执行真实付款。

## 在原书架共读

1. 小屋第三页 → 原来的书架，导入 TXT / Markdown。原书、封面与本机进度继续保存；原本的书架备份格式保留。
2. 打开“书目 / 封面”，点“开启共读”。只有主动选择的这一本原文会保存到私密小屋，其他本机书籍不自动上传。
3. 打开书阅读。章节、按 Unicode 字符定位的书签与当前可见段落长度会同步；本机进度也保存。共读冲突/网络错误会显示状态并保留本机进度，不盲目覆盖另一端书签。
4. 点“回聊天共读这一段”，位置确认后回北极星，在聊天里说“一起读当前这段”。不自动发送消息、不覆盖现有聊天草稿。AI 先看 `reading_list` 的最近活动书签，再用 `reading_read` 按位置取原文。
5. 可先选中原句再打开“摘录与读后感”，或直接留下想法。摘录须在指定章节原文中，作者区分本人和阿昼；同内容重试避免重复笔记。笔记在单独的原风格页面，不挤占阅读正文。
6. “接上共读书签”可主动定位到共享位置；“停止共读”暂停原文读取，本机原书和已保存笔记保留。需要时可以恢复。

默认读取当前段落；无可见长度时默认约 1200 个字符，单次最多 6000 个 Unicode 字符，并提供下一段/下一章指针。不会因导入或翻页就把整本书送给模型；读原文是只读动作，不自动把整本书标记为读完。工具目录仅含书目/书签，笔记全文按明确请求读取。

新增共读工具：`reading_list`、`reading_read`、`reading_progress_save`、`reading_note_save`、`reading_book_update`。网页导入原书使用受保护的浏览器接口，模型不获得任意文件上传或网页执行能力。书名/作者可与共享书目同步；原文按内容哈希保存且不可覆盖。

从其他浏览器取回已共读原书时，先校验原文哈希再存入本机。原书内容/章节解析与原阅读器共用同一份纯函数代码，避免双方章节编号或表情字符偏移不一致。封面仍为本机资料。

## 导出与数据边界

- Android 补充原小屋 TXT、JSON、CSV 下载处理：只响应本人点击的同源 blob 下载，原生再次检查页面/链接来源、类型、文件名和体积，分块读取后由本人在系统文件选择器指定保存位置。无远程原生 JS 接口、无静默任意路径写入；文件写入在后台执行。
- App 内单次导出上限 16 MB，大书架可以按本书分批导出。原书架备份含本机原文、封面和阅读进度；单本书也可导出。没有把这些 WebView 文件说成已包含在 Polaris 聊天 ZIP 备份中。
- 新增附加的生活版本表，不改写原账目和其他原表。私人后台备份纳入新表，增加共读原文单独导出；原平台和数据库身份不变，不扩大访问范围，不索取密码、token、API Key 或签名密钥。
- GitHub 仍是主记忆，Notion 仍为正式日记；本轮不代写私人日记、不导入尚未收到的官端聊天，也不接手机点击。

## 开发验证与手机验收

已用合成内存数据库检查超出一页的月汇总、整数金额、预算并发/重试、账目限定的收起恢复、账号隔离；原文保持、重复导入、章节一致性、Unicode 书签、按段读取上限、真实摘录、笔记去重、停止/恢复共读、备份覆盖。客户端实际脚本的 Node VM 检查未知记账结果核对、刷新失败不变成写入失败、旧草稿清理、共读书签恢复、激活、避免重复写和冲突停止。

原生策略及实际导出脚本另有自动检查。当前环境无可用 Sites 浏览器 QA 接口，未把 Node VM 当成真实 WebView 操作或视觉验收。原主页结构/背景素材单独做字节核对；真实账目录入/CSV 保存、本人书籍开启共读、翻页后 AI 读回及文件恢复仍需本人安装后核对。
