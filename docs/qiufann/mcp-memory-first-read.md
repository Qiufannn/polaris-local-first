# 小家记忆：独立原生授权与首次只读验收

## 当前结果和边界

原中枢在官端的 memory_status → memory_bootstrap 已实际成功，确认持久层与接续包正常；这不代表 Polaris 已接通。已检查原 Site 访问配置、MCP 连接元数据和当前服务源码：支持 initialize / server/discover、JSON-RPC tools/list 和 tools/call，业务工具要求平台传入已认证访问者身份。原 Site、数据库、发布版本和访问范围没有更改，没有使用服务访问凭据替代访问者身份。

Sites 返回准确的 MCP endpoint 和 OAuth resource。本轮为 Android 增加独立公共客户端 OIDC/PKCE 入口，资源由本人填写的原 Site HTTPS /mcp 地址绑定。**公开的动态注册文档确认了模型 API 的资源流程，但没有找到它保证所有私人 Site 都接受 dynamic_agent_client 的说明；因此这个 Site 资源的独立授权/访问资格必须在本人手机验证，不能把代码测试通过写成已读到记忆。** 如果授权端或 Sites 拒绝该资源/客户端，就保留失败状态，继续按支持的接入方式处理。

## 实现

- 新增 Android McpSiteAuth 桥和 Sites 资源策略，只接受 HTTPS、*.chatgpt.site、精确 /mcp，无用户信息、端口、查询或片段。网络请求拒绝重定向，采用有限超时和响应上限。资源校验不代表本人拥有该站点；最终资格由平台授权和服务访问检查决定。
- 复用经过测试的 PKCE/state/nonce/JWKS/身份校验流程，为每个服务 ID + 资源 URL 建立独立加密凭证空间。原 ChatGPT 模型凭证的目录、key alias 和 AAD 保持原字节值；MCP 使用新的资源绑定 key alias / AAD 和 noBackupFilesDir，重用同一安装的非秘密 host ID。
- 独立请求 openid/profile/email/offline_access/resource.invoke；不请求模型订阅 scope，不读取模型凭证。响应明确声明其他 resource 或返回模型订阅 scope 时拒绝保存。刷新按资源绑定、串行替换，失效/断开不影响聊天和模型授权。
- 凭证不返回 WebView、不进入普通 MCP headers 或导出。普通配置只保存 authKind=sites-memory-oauth 标记、服务 ID 和非秘密 URL。目录发现、缓存、实际调用均携带同一认证类型；缺桥、网页环境和旧 SSE 不做匿名回退。
- 本轮客户端仅允许 memory_status、memory_bootstrap、memory_recall，目录会过滤到这三个工具；写入、恢复、生活记录和任意代码工具均被原生策略拒绝。检索强制排除 sandbox 且只检索已确认记录，接续包使用 other 窗口，不冒充已注册的官端日常窗。
- “只读”指客户端开放的业务操作；服务正常记录读取回执。OAuth 授权页的实际范围由提供方决定，不声称服务端签发了专用只读 scope。
- 编辑器新增“小家记忆（独立登录，只读）”。先保存地址和类型，再打开服务卡完成本人网页登录；验证按钮依次调用状态和接续包，必须有非空记录及服务返回的读取回执才显示成功。该预览不自动导入普通长期记忆，不自动上传聊天原文。

## 手机操作（更新包交付后）

1. 同签名覆盖安装新版，不卸载旧版。
2. 晏昼 → 请求 → MCP，保持不跟随所有 MCP，新建服务：填写原小家名称、原 HTTPS /mcp 地址，连接方式选“小家记忆（独立登录，只读）”，保存。
3. 重新打开该服务卡，点 Continue with ChatGPT，在系统浏览器选择拥有原小家的账号并完成授权，再返回 App。若浏览器拒绝，不复制含授权码的网址，只报告普通提示文字。
4. 点“验证只读接续包”；只有明确显示真实记录与回执才算本次读取成功。再点测试连接同步工具，并保存服务。
5. 确认工具箱 MCP 开启，晏昼选中了这个服务。在该角色聊天里明确要求先查看记忆状态、再读接续包，核对实际引用的记忆和回执。
