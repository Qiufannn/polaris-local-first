# 聊天行动记录显示

本人希望把 GitHub 读取等连续工具记录合并收起，日常聊天只显示说话内容。旧版只有逐条收起工具详情；此次增加全局显示偏好，不修改消息、工具执行、模型上下文或 GitHub / Notion 授权。

## 手机入口

左上角菜单 → 显示与触感 → 行动记录显示：

- **逐条显示**：保留各条工具记录。
- **合并折叠**：默认选项，把连续且没有聊天正文/成果的工具过程收成一条“行动记录 · N 项”，点开查看原有记录，再点可收起。
- **隐藏已完成记录**：隐藏常规过程和任务浮条；正文、图片、文件和生成卡片继续显示，失败及需要本人确认的操作保留入口。

设置立即生效，并通过已有 LocalData 显示偏好保存。旧设置缺少新字段时默认合并折叠；导入未知值也回退到折叠。仅改变显示，切回逐条显示即可恢复记录；没有删除聊天或工具结果。

## 实现边界

在原时间线 render items 上添加显示投影，先按连续工具过程分组再做虚拟窗口计算，不能跨用户消息或真实聊天正文合并。原 tool-runtime 消息和消息顺序不变；普通代码答案不会因为代码围栏被误当作工具。执行相关代码可以随过程收起，图片、文件、卡片成果保留在对话里。

组合行使用稳定 ID；打开组合后测量整组高度，避免子行覆盖父组缓存。查找/聚焦到组内消息时，虚拟窗口保留所在组并打开它。隐藏工具过程后恢复首条可见正文的协作者身份显示，避免原首条空工具消息消失导致头像也丢失。
