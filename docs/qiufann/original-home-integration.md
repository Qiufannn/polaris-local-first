# 原小屋启动与北极星聊天

## 当前要求与实现

本人明确要求保留原私密网站的完整三页、头像、雪景/雨夜、时间与日历等排版，不重新绘制小桌面，也不做自由装修。应用冷启动先打开原小屋；点击原网页已有的聊天入口才进入北极星聊天。应用全局的“回到家园首页”可重新打开。此前 21 版聊天内固定六项入口已移除。

Android 使用独立、无 Capacitor/JavaScript 原生接口的 WebView 加载本人原网站。只在同一原站页面注入原聊天按钮的跳转监听；不替换任何 HTML/CSS、组件、图片或数据库。不复制私人网页素材到公开仓库，不重新部署网站，不更改其可见范围。应用升级不会改写原网站的三页设计。

初次尚未设置原网址时只有一个配置页。原网址按协作者保存在原有 `advanced.homeUrl` 字段，支持不含密码、参数的 HTTPS `*.chatgpt.site` 首页地址。已有网址会自动打开；网页关闭或连接失败后也可先进入聊天，不阻塞原有工作区、草稿与消息。Web 预览只能在浏览器打开网站，不伪装成 Android 内嵌小屋。

## 手机设置与验收

1. 用个人签名更新包覆盖安装，保留现有 Polaris 数据。
2. 首次启动填入本人原小屋首页地址，保存并打开。已有正确地址无需重填。
3. 在 App 内原网页正常登录；Via/Edge 的登录不会自动复制到独立 WebView。不要把密码、验证码或 Cookie 发到聊天。
4. 核对原三页、头像、主题、日历和入口；点击原来的“聊天”进入北极星。
5. App 实际读取原站 `home_list` 成功后才建立/启用“原小屋” MCP；读取失败会提示，可在请求 → MCP 内打开原小屋并登录、重新测试。
6. 用一条明确指定的测试待办做双向验收：在原页填写后由 AI 读回，再让 AI 更正并在原页刷新检查。不要用真实旧记录做破坏性测试；网络超时先查记录，不重复提交。

真实手机的内嵌网页登录、站点网关接受该会话、真实记录写入/回读仍待本人安装后核对。开发环境合成验证不能替代这一验收；未宣称跨端自动同步或真实写入已成功。

## 三页记录与 AI

网页原来的表单继续走原站后台；原小屋 MCP 走同一站点 `/mcp`，不是另建一套 Polaris 假数据。目录来自当前后台，只有实际发现且经过筛选的工具才对模型可见：生活记录读取、日历、双人心情、账本、待办、照片说明/查看、歌曲、健康、故事、带回的小物与已有花园活动记录，以及只读记忆工具。工具没有实际返回的功能不会凭空出现。修改已有记录仍应先读版本、使用稳定请求编号、写后回读；AI 可以在实际对话中根据本人引导填写，不能宣称后台无人运行。

GitHub 仍为主记忆，Notion 为正式日记，北极星日记仍走已有独立 Notion 连接。这个小屋连接不自动上传聊天、不开放原站聊天归档或主记忆改写，也不调用仅支持 Chat/Work 的日记镜像工具。小屋活动记录不等同花园账号本体；已有花园 OAuth 连接继续保留。

原网页中仅存在浏览器本地的导入书籍、音频和主题偏好不会从另一个浏览器自动搬入，也不自动成为 AI 可写的远程记录；可沿用原网页的导入/导出。Polaris 手工备份不包含独立 WebView 文件。原有文件选择已接入；媒体后台播放、设备录音与各种网页下载行为未全部做手机验收，不据此宣称完整 Aru 小应用融合。

## 登录与数据边界

原站会话仅由 Android CookieManager 保存和提供给本人刚打开的精确同一 HTTPS 原站 `/mcp`。凭证不进入 JS、提示词、工具参数、日志或 Polaris 导出；系统备份排除独立 WebView 目录。远程网页没有调用 Polaris 原生接口的能力。

原生传输不接受模型提供的认证头，不伪造站点用户身份；禁止跨源重定向和匿名回退。未登录、网关拒绝或返回登录 HTML 时安全失败，不把工具目录可见当成记录读取成功。不自动重试未知结果的写入。

## 技能引用资料修正

仅在原文《书名号》中出现的标题现在作为可选资料线索，不再自动认定成必需原文。已在可用主记忆与固定 Notion 日记范围查询，未找到此前两份标题对应的独立正文；不虚构它们存在，也不要求本人寻找不存在的文件。

技能页可删误识别线索、粘贴真实资料，或明确勾选“设为必需”。只有明确必需而缺失的资料才阻止加载正文；可选缺口会说明未提供，禁止模型装作已读。技能文字不能复制官端工具、验证状态或平台权限。
