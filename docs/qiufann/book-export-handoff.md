# 原小屋书架备份下载交接

2026-11-16 本人反馈：北极星完整备份可以导出，原小屋书架备份在点击准备好的下载链接后弹出“请重新点击小屋里准备好的下载链接”。该提示来自现有原生下载脚本的页面/来源/点击标记检查，不能据此声称文件已保存。

原来书架 `homeDownload` 只准备带 download 属性的 blob 链接，依赖原生在页面加载时装上的 document 点击监听来登记标记。源码修正为链接本身在可信点击时写入相同交接信息；如所在页面嵌在同源顶层中，也将 URL、文件名和时间交给同源顶层。不同源顶层不接收，不复制文件内容、Cookie 或凭证，不放宽现有原生来源、类型、体积和系统文件保存限制。原书数据、封面、阅读进度、书架结构及三页样式均未更改。

使用实际书架导出函数和现有 Android 下载脚本组成联合检查，在缺少原生页面级点击监听的场景先复现同样错误；修复后验证独立页面、同源子页面均能读取原样 JSON 与 Unicode 原文/进度，未点击及程序点击不新增网页交接记录，不向不同源父页交接。该检查使用 Node VM、合成 DOM/数据，不等同于真实 WebView 或本人文件保存验收。账本和共读的原客户端检查、生产构建与 Worker 语法检查通过。

原私密小屋第 40 版发布成功，源码 `577dc07168e680cf0f930ac430bcc20c303af9eb`。源改动仅书架脚本和合成测试脚本，没有修改数据库或访问范围；仍为同一 owner-only Site。Android 安装包不变，现有第 27 版即可接收网页修复。
