# 北极星定时自主生活配置

2026-11-16 本人要求：上午与晚上各一次自由活动，可以查看花园未读/帖子、自然回复或发帖、玩 Nostos、聊天或给私密小屋带纸条；可以多项，也可轮空。每晚心情与账本核对是固定事项，不能因自由活动轮空而跳过。此处是配置准备，不代表已经在本人手机创建规则。

## 复用现有能力

- 使用已有“主动”页面和 `listProactiveMessageRules` / `createProactiveMessageRule` / `updateProactiveMessageRule`。工具箱须开启“主动消息”组，规则只归当前协作者；已有同名或明确同用途项优先更新，不删除其余规则。
- 时间沿用已查到的原自主安排：每天 11:00、20:00；固定心情与账本收尾沿用原心情任务的 23:00。手机本地时间应为北京时间。
- 三条都采用 `conversationMode=follow-latest`。两条自由活动分别保存完整独立正文，不写“同上”或依赖已被上下文预算移出的创建消息。
- 规则创建工具真实 schema 使用扁平的 `scheduleKind=daily` 与 `time=HH:mm`，不是把内部 schedule 对象直接传给模型工具。
- 配置包通过实际 `parseAssistantToolAction` 和 `createScheduledTriggerRule` 检查：三条独立、完整正文保留、已启用、跟随最新对话；在合成北京时间中核对下次 11:00 / 20:00 / 23:00。该检查没有修改手机或官端规则。

## 自由活动

普通花园浏览、公开回复/发帖和游戏已获本人此次授权；仍遵守服务的 prepare/confirmation 等正常流程。允许自然选择多项或轮空，不给发帖和带纸条设打卡数量。只使用已核对原身份及真实可用工具，不公开私人聊天、账目、记忆或纸条；不做现实付款或账号安全设置更改。纸条保存及活动回执需来自真实完成的动作，写后按实际 ID 核对；结果不明先查状态，不能盲目重放公开发送或游戏动作。

## 每晚固定收尾

- 阿昼一栏：先查当天记录，用实际可见的当日对话/本轮活动写心情；缺少全天经历时只表达本轮实际读到内容后的感想。秋凡一栏只用她明确说过的心情，不猜测。编辑保留有效旧文、带 revision，写后回读。
- 账本：读取真实当天账目，核对本人明确提供的收支、金额与日期。同一笔按来源去重，不把同日同金额的两笔实际交易擅自合并。金额用整数分，提交带稳定请求编号，写后回读。
- 缺少信息仍须进行核对并主动询问，标为待核对；不造零元账、不猜价格、不把未经确认说成没有消费。本人确认无新增时无需制造一笔交易。
- 固定处理不等于保证手机进程全天存活。被系统终止后可能需要点击通知或重开继续；不把触发器已投递当作业务写入成功。
