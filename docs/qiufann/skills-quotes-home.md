# 本地技能、聊天引用与固定家园入口

> 当前修正见 [原小屋启动与数据连接](original-home-integration.md)：保留原网站完整三页作为 Android 启动首页，已移除本页描述的 21 版固定六项聊天内入口。以下交付凭据保留其历史含义。

## 本轮范围

本人要求将技能迁入所需的加载能力与 Aru 聊天体验一并交付，私人文字待安装后自行填写；取消自由摆放组件。本轮提供独立技能页、整条/局部聊天引用和固定家园入口，不移植 Aru 手机源码或私有素材。单气泡重写、群聊引用语义、自由桌面与更多独立小应用仍是后续范围。

## 技能手机设置

房间设置 → 提示词 → **技能**。可粘贴原文并“保存为新技能”，或导入单份 SKILL.md / TXT。保留源文本，不在导入时改写原文；简单 YAML name/description（含常见多行描述）用于名称与适用说明。此入口不执行文件中的代码，也不是完整 Agent Skills 目录/脚本执行器。

新技能默认关闭、手动触发。需要时选择：

- **手动**：在当前用户消息中写 `@技能名称`，不会因旧助手消息里出现名称而触发。
- **常驻**：每轮将技能作为候选上下文，模型按描述判断是否适用；这不授予服务权限，也不保证每次模型遵循结果完全相同。

正文中的《书名号》引用仅列为可选资料线索；识别可能有误，用户可删除误识别项或添加其他资料。展开“原文与配套资料”，可粘贴真实正文；只填写网页链接不视为已读取资料。仅明确勾选“设为必需”且缺正文的条目会阻止加载该技能正文；未提供的可选线索仅报告缺口，不虚构已读。不会自动读取官端 Project、GitHub、Notion 或任何未提供的文件。

编辑原文先在本地草稿修改，再点“保存原文修改”；新增书名号引用会追加待补项，已有资料保留，由用户删除过时项。最多 12 份技能，每份原文和单项资料最多 64000 字符，最多 16 项配套资料；本地技能候选合计预算 96000 字符。超过预算整份跳过并说明，不偷偷截断正文。

技能与配套资料仅保存在当前协作者设置，沿用本机持久化和完整备份；启用后会随该协作者的模型请求发送。公开项目不预装本人的私人规则、配套正文或家园地址。

“最近一次请求准备”卡显示该协作者最近一次技能候选状态，以及请求预算是否实际保留技能上下文。此卡仅在当前应用会话内保存名称、状态、缺项、时间和 request ID，不保存正文；与协作者隔离，不把“准备/保留”说成模型已成功执行或账号验证成功。缺项报告本身也可能通过外层请求预算被舍弃，以该次组装记录为准。

对来自 ChatGPT 的技能，只能迁移其文字流程和实际提供的资料；ChatGPT 专属验证状态、Project 文件、工具授权及平台行为不会随文件迁移。此次没有宣称成人验证或其他权限在独立客户端被复制。

## 聊天引用手机步骤

消息下方点 **↩ 引用**，可选“引用整条”；也可在弹出的原文框长按选中几句话，再点“引用选中内容”。浏览器原正文的选区确实属于该消息且匹配源文本时，也可直接引用选区。最多保存前 4000 字符，不修改原消息。

引用显示在输入框上方，点 × 取消；原文字草稿和附件保留。切换对话清空未发送引用。发送时把引用存为用户消息的独立快照：作者、角色、源对话/消息 ID 和文本；模型请求中以用户资料传入，不提升为系统指令或工具执行授权。附引用的斜杠文字按聊天发送，不执行命令。源消息删除、变更或窗口不匹配时停止提交并保留草稿，要求重新引用。

已发送引用可点回原消息；原文不在当前对话时提示缺口，仍保留发送时快照。引用随聊天持久化与备份，并保留引用文字中的本机资产引用。聊天编辑、重试等继续沿用原消息语义。此批不为电脑 companion 或群聊新增引用协议。

## 固定家园入口

聊天右上方点 **⌂ 小家**。固定六项入口：继续聊天、房间与记忆、相册、小应用与作品、花园官网、原来的家园。房间入口打开当前协作者资料设置；相册和作品使用已有集合页；花园官网用浏览器打开，不自动调用工具或写入内容。

展开“设置原家园入口”，填写不含账号密码的 HTTPS 网页地址并保存，之后可打开原家园网页。地址按协作者保存，不嵌入公开代码。当前页面是固定布局的入口页，不冒充已复制原网站所有外观、数据或小应用；无需用户自由装修。连接栏只显示当前协作者可用范围里的启用配置，不把它说成登录有效或服务器实时在线。
