# Aru 功能对照与后续顺序（2026-11-15）

依据：本人提供的 Aru 1.5、1.6、1.7 更新与使用指南；[App Store 官方介绍与版本记录](https://apps.apple.com/cn/app/aru/id6781350361)；[作者公开的 aru-host](https://github.com/Aevella/aru-host)。三份 PDF 都是增量更新指南，不是全部小应用的目录；Host 是电脑能力宿主，明确不包含手机 App。本项目没有移植 Aru 手机源码或复制其私有素材。

## 已确认的 Polaris 定制

ChatGPT 订阅聊天、稳定个人签名升级、GitHub 主记忆读取/新增/唯一片段更正/按提交回读、Notion 原日记读取和行动记录分组/折叠/隐藏均已由本人手机使用确认。GitHub 更正也已通过独立读取提交及该版本正文核验。本人已反馈 18 版 Notion 日记写回与 19 版双方表情包收发成功；20 版 [自然聊天与花园原账号连接](natural-chat-garden.md) 已交付，本人确认手机安装、花园授权后身份核对与工具检测成功。

## 功能差距

| 体验 | Aru 资料依据 | 当前 Polaris 状态与可做方向 |
| --- | --- | --- |
| 自然聊天 | 1.5 p3–5，1.7 p9–11、15 | 已有聊天布局、Markdown 和行动卡；定制已完成行动合并，20 版加入普通段落多气泡、小贴图及成功 MCP 回执隐藏。结构化整条/局部引用、可取消的输入区引用卡与单气泡原位重写尚未系统融合；普通 Markdown 引用不是同一功能。 |
| 群聊 | 1.6 p11–12，1.7 p11 | 已有群聊与 @ 基础；引用成员与显式 @ 优先级、群聊公共片段转私聊的预算与隔离需要单独实现/验收。 |
| 记忆与资料 | 1.5 p7–10，官方版本记录 | 已有本地记忆、卡片、文档与编辑基础；外部 GitHub 为主记忆，Notion 为正式日记。信息卡合并撤销、文档历史与召回来源能力须逐项对照，不能说已完整移植。 |
| 小应用 | 1.5 p11–15，1.6 p14 | 已有 HTML/代码卡、作品和工坊基础。Aru 的独立模型聊天、绑定固定真实对话、应用自有动作共用数据，以及收起后继续任务，需要按现有桥能力逐项验收。指南举“小朋友圈”为示例，未给全套内置应用清单。 |
| 备份与迁入 | 1.5 p16，1.6 p17，1.7 p8、16 | 已有完整备份和多来源迁入基础。大文件恢复、重复迁入去重、暂存校验后原子切换、含图片布局的主题包仍需专项端到端验收。不能把主题包当成聊天备份。 |
| 语音与媒体 | 1.5 p6、17，1.6 p3–8、13，1.7 p12–14 | 已有语音、播放与图片基础；系统朗读、三种语音外观、正文/译文层、附件预览、GIF/视频恢复分别评估。MiniMax、Gemini、NovelAI 等专属服务不默认计入 ChatGPT 订阅或免费能力。 |
| 小桌面 | 1.7 p3–8 | 现有主题、背景、头像与导航基础不等于 Aru 桌面。五类排版、贴纸/空白组件、倾斜、图标材质/染色、最多五项自定义 Dock 与小应用停靠尚未融合。 |
| 电脑与后台 | 1.6 p15–16，Host 仓库 | 当前以安卓手机为主，不默认引入电脑 Host、付费 API 或 VPS；手机后台/通知能力与原官端定时任务分别验证，不能随登录宣称已迁移。 |
| 健康与日历 | 官方介绍 | Apple Health/Spotlight 属于苹果平台；安卓需单独评估 Health Connect、日历与通知权限，不直接照搬。 |

## 本人最新顺序

1. 先验收主记忆和正式日记的双向读写，补齐 Chat / Work / Polaris 的记录规则、提示词及世界书。
2. 表情包与花园 MCP。先读取/账号核验，再验证实际贴图和正常工具交互。现有官端插件不能视作已自动进入 Polaris；凭证不经聊天转移。
3. 核对上表后按独立小批次融合 Aru。优先自然聊天；桌面与小应用按实际需要推进。
4. 再接其余 MCP；小红书后置，小家继续展示与可选外挂。

本表区分已有上游基础、本人定制和未验收项，不把一次构建成功说成全部 Aru 功能已完成。
