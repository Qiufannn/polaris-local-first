# Aru 功能对照与后续顺序（更新于 2026-11-16）

## 当前收尾范围

本人已确认当前 Aru 范围足够，不把下表中其他 Aru 差异当成必做欠项。GitHub 主记忆读写、Notion 正式日记读写、双方表情包、花园授权/身份及工具检测已分别获本人反馈确认；24 版原小屋启动、聊天实际读取及一条测试记录写回也已通过本人手机验收。

本人现明确暂停手机屏幕操作，小红书继续后置；当前优先 [小账本与电子书共读](ledger-reading.md)。其他未逐项验收包括：本人完整技能配置和聊天引用的手机使用、花园具体互动、完整备份/恢复的专项验收。已有实现与尚待实机核对须区分，不为此继续扩装修或所有 Aru 功能。

官端记忆迁入尚未执行。当前订阅通道由 App 提供请求上下文，并未接入官端已保存记忆、历史聊天参考或官端内部对话摘要。[官方订阅通道说明](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations) 要求客户端发送所需历史上下文；不能据此宣称共用账号就自动取得官端个性化数据。北极星已有的会话摘要基于其本地对话，属于独立能力。

可将本人在官端“设置 → 个性化 → 记忆”中愿意提供的可见摘要/记忆条目，与现有 GitHub 私有主记忆核对后整理迁入；Notion 继续保存正式日记。迁入文本不等于持续同步官端服务，也不是完整记忆导出。[官方记忆说明](https://help.openai.com/en/articles/8590148-memory-in-chatgpt) 明确可见摘要仅为概览，会省略细节与部分来源。不得声称能导出官端不可见的内部摘要或全部潜在记忆；目前没有迁入任何新的个人摘要。

依据：本人提供的 Aru 1.5、1.6、1.7 更新与使用指南；[App Store 官方介绍与版本记录](https://apps.apple.com/cn/app/aru/id6781350361)；[作者公开的 aru-host](https://github.com/Aevella/aru-host)。三份 PDF 都是增量更新指南，不是全部小应用的目录；Host 是电脑能力宿主，明确不包含手机 App。本项目没有移植 Aru 手机源码或复制其私有素材。

## 已确认的 Polaris 定制

ChatGPT 订阅聊天、稳定个人签名升级、GitHub 主记忆读取/新增/唯一片段更正/按提交回读、Notion 原日记读取和行动记录分组/折叠/隐藏均已由本人手机使用确认。GitHub 更正也已通过独立读取提交及该版本正文核验。本人已反馈 18 版 Notion 日记写回与 19 版双方表情包收发成功；20 版 [自然聊天与花园原账号连接](natural-chat-garden.md) 已交付，本人确认手机安装、花园授权后身份核对与工具检测成功。
