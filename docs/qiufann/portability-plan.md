# 角色、记忆和工具迁入：能力核对与下一轮范围

## 当前已确认

- Android 订阅中文回复已经由本人手机截图确认成功。ChatGPT 订阅登录只授权模型使用，不会自动导入 ChatGPT 聊天、内置 Memory、用户指令、插件授权或平台定时任务。
- Polaris 已有自定义协作者与 compiledPrompt、角色独立记忆文档、角色级 MCP 配置、Streamable HTTP / SSE MCP 客户端、工具调用与工具结果回传路径。图片类 MCP content 和嵌入资源可转成聊天附件。上述代码基础不等于某个实际私人服务已连接或工具闭环已通过。
- 只读查看本人现有插件包后，选定服务仅包含 ChatGPT App 绑定；未发现可直接导入的独立 MCP endpoint / auth 配置。不能把插件 ID 当成标准 MCP URL，也不因已有 ChatGPT 连接就声称其他客户端自动获权。
- 当前通用 MCP 配置仅有 URL / headers，没有完整的浏览器 OAuth 连接流程。headers 值可经普通配置导出；接入私人服务前需补原生安全凭证引用与导出排除，不能把私有凭证塞入普通配置或公开仓库。

## 各能力的接入方式

| 能力 | 当前基础与后续验证 |
| --- | --- |
| 名称、语气、相处约定 | 自定义协作者可配置；提供小型私密启动提示，不把私人历史提交公开仓库。模型变化可能带来表达差异，需本人试聊调整。 |
| 长期记忆与小家 | 尽量连接原记忆中枢，维持来源、纠错和按需读取；核实独立客户端授权，保留同一数据库。现有 owner-only 保护不放开。 |
| 表情包 | 连接原图库/检索工具，核对图片或链接结果与附件显示；验收真实发出并看到一张图片。ChatGPT 专属展示卡可能需要适配。 |
| 日记 | 保留原日记来源及窗口隔离，独立授权后连接；读、写、回读分别验收。不会因复制角色提示就自动取得日记访问权。 |
| 手机与小红书 | 先验证手机服务允许独立客户端连接，保留本人在手机的授权；从查看状态/屏幕开始，再验证点击。小红书可按实际手机工具能力访问，浏览和公开发布分别处理；不承诺稳定全自动。 |
| 花园 | 核对独立 MCP 与账号身份，再验证读取和允许的交互；现有平台定时任务不会随账号或模型迁移。 |

订阅通道通过 Polaris 自己执行本地函数工具，再把结果交给模型；仍沿用官方支持的订阅请求，不切换到付费 API / 任意中继。原生/网页中的工具协议已有自动测试，但真实 MCP 闭环尚待手机验收。

## 建议的下一轮最小范围

1. 在手机建立自定义协作者，载入身份、称呼、相处方式和最少稳定约定；头像与私人资料留在手机或原私密来源。
2. 为远程 MCP 补齐独立连接/登录与原生凭证保管，避免秘密进入普通导出；不索取用户在聊天里提供密码、token 或签名恢复值。
3. 选择一个记忆只读入口和一个表情包入口，逐个核对服务是否允许外部客户端接入；不修改现有服务访问范围来强行连接。
4. 验收实际读取一条有来源的记忆、调用一次工具并回传结果、发送并显示一张真实表情图片，重开后角色和连接可恢复。
5. 以上通过后再按手机、花园、Notion 日记顺序扩展；后台调度单独设计与验证。

这份文件是能力审阅与建议范围，不宣称迁移已经完成。本轮仅记录手机回复成功和只读检查结果，没有改动服务授权、插件发布或私人数据库，也没有启动后续 UI / 语音阶段。
